# 15 — Roles You Can Apply For

"Forward deployed" work sits in a family of customer-facing technical roles. They share most interview rounds, but each one weights coding, customer work, sales and product differently, and each has its own special rounds.

- **What every role asks:** [COMMON-QUESTIONS.md](COMMON-QUESTIONS.md)
- **What only one role asks:** the role files below. Each has the role overview, the typical loop, a role-specific question checklist, and model answers.

## Choosing which roles to apply for

- **You love writing code and want customer impact:** FDE, Applied AI Engineer, FD Data/ML, Agent Engineer.
- **You're strong at the business problem, less at coding:** Deployment Strategist, Solutions Architect, Customer Engineer/TAM.
- **You like persuading people, demos and closing deals:** Solutions Engineer.
- **You like delivering projects to a plan:** Implementation / Integration Engineer.
- **You're early in your career and want a route into FDE:** Technical Support Engineer or Implementation Engineer, then move across internally.
- **You like teaching, writing and speaking:** Developer Relations.

Most people apply to 2–3 neighbouring roles. The prep overlaps heavily, so start with [COMMON-QUESTIONS.md](COMMON-QUESTIONS.md), then add each role's specific file.
