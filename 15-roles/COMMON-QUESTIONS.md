# Common Questions — Asked in Every Customer-Facing Technical Role

Whatever title you apply for (FDE, Solutions Engineer, Solutions Architect, Applied AI Engineer, TAM, Implementation Engineer, Support Engineer, DevRel), these questions come up again and again. Master them first, then add the role-specific file from [README.md](README.md).

Each question links to its model answer elsewhere in the repo.

> Priority: **Tier 1** is asked in almost every loop. **Tier 2** comes up in most technical loops. **Tier 3** is asked often enough to prepare.

## Questions you should always ask them

See [14-questions-to-ask](../14-questions-to-ask/README.md). These three work for every role:
- What does success look like in the first 30/60/90 days?
- What's the hardest part of this role that candidates underestimate?
- How does feedback from the field make it back into the core product?
