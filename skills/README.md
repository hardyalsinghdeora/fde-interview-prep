# Skill-wise question lists

Practice lists by **skill**, complementing the round-based banks in [topics/](../topics/) and the
role guides in [roles/](../roles/README.md). 26 skills, 951 questions, each list in five
levels: fundamentals → working depth → senior/principal depth → scenarios → hands-on checks, ending with
what a principal-level answer shows and a small project that gives you a real story.

Ordered by what a real job search for Principal / Staff / Architect / AI roles in India asked for
(113 postings assessed, October 2026).

## How to use

1. Tick a question only when you can answer it **out loud in two minutes**, with a real example.
2. For gaps, do the **Prove it** project first — one real build beats ten memorised answers.
3. Turn your best answers into stories in [my-prep/STORY-BANK.md](../my-prep/STORY-BANK.md).
